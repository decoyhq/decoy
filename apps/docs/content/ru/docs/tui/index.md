# Терминальный интерфейс

Запустите `decoy` без подкоманды, чтобы открыть сервер с интерактивным журналом запросов. Поддерживаются те же флаги, что и у `decoy serve`. Нажмите `/`, чтобы ввести команду. Команды действуют в активной Session. Изначально это `default`; другую можно выбрать через `/session`.

## Команды

| Команда                        | Действие                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------ |
| `/collection <id>`             | Переключить Collection активной Session.                                       |
| `/route <route:case:behavior>` | Выбрать Behavior для Case Route в активной Session.                            |
| `/reset`                       | Удалить переопределения активной Session, сохранив её Collection.              |
| `/session <id>`                | Сменить Session, к которой относятся команды; новый ID создаёт Session с нуля. |
| `/sessions`                    | Показать Sessions, для которых сохранён Selection.                             |
| `/status`                      | Показать Collection и переопределения активной Session.                        |
| `/show <id>`                   | Открыть запрос в панели сведений.                                              |
| `/reload`                      | Перечитать конфигурацию без перезапуска.                                       |
| `/help`                        | Показать команды и клавиши.                                                    |
| `/quit`                        | Остановить сервер и выйти.                                                     |

## Перечитывание конфигурации

`/reload` перечитывает конфигурацию из тех же файлов и с теми же флагами, с которыми запустился `decoy`, а затем применяет новые Routes, Collection и настройки. Лимит `maxBodyBytes` берётся при поступлении запроса, а Routes и Selection — после чтения тела. Поэтому запрос, тело которого ещё загружается во время перечитывания, сохраняет старый лимит, но сопоставляется по новой конфигурации. Если новая конфигурация не загрузилась, `/reload` выводит ошибку, а старая остаётся активной.

Точки прослушивания остаются привязанными к исходным адресам. Изменение порта, адреса, `listeners` или TLS требует перезапуска, о чём `/reload` предупреждает сообщением `listener changes need restart`.

Каждая Session сохраняет свой Selection, кроме трёх случаев:

- Session, которая не выбирала Collection, переходит на новую Collection по умолчанию.
- Если выбранная Collection исчезла, Session возвращается к Collection по умолчанию с предупреждением.
- Переопределение удаляется с предупреждением, если его адрес `route:case:behavior` больше не существует.

## Клавиши

| Клавиша                                   | Действие                                                                                                        |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `↑` `↓`                                   | Перемещаться по списку подсказок; если он закрыт — по истории ввода.                                            |
| `Tab` / `→`                               | Подставить выделенную подсказку.                                                                                |
| `Enter`                                   | Выполнить введённую команду; если список подсказок открыт — дополнить команду и выполнить её, когда она полная. |
| `Esc`                                     | Закрыть список подсказок или панель сведений.                                                                   |
| `Ctrl+O`                                  | Выбрать один из недавних запросов.                                                                              |
| Щелчок по запросу                         | Открыть сведения (`PgUp`/`PgDn` прокручивают их).                                                               |
| `PgUp` `PgDn` `Home` `End`, колёсико мыши | Прокручивать журнал.                                                                                            |
| Перетаскивание                            | Выделить и скопировать; с `Shift` используется выделение самого терминала.                                      |
| `Ctrl+U`                                  | Очистить строку.                                                                                                |
| `Ctrl+C`                                  | Очистить строку; два нажатия завершают работу.                                                                  |
| `Ctrl+D`                                  | Выйти, если строка пуста.                                                                                       |

`Enter` после `/session <id>` переключает Session на введённый ID, даже если список предлагает более длинный знакомый ID. Чтобы принять подсказку, сначала нажмите `Tab`.
