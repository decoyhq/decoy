# Примеры для запуска

В каждом примере есть файлы моков и клиент или набор тестов, которые можно запустить из репозитория Decoy.

| Пример                                                                                                       | Что показывает                                                                |
| ------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| [Playwright](https://github.com/decoyhq/decoy/tree/main/examples/playwright-ts-e2e)                          | Как переключить ответ, который получает страница в браузерном тесте.          |
| [Testplane](https://github.com/decoyhq/decoy/tree/main/examples/testplane-ts-e2e)                            | Как направлять запросы браузера в отдельную Session для каждого теста.        |
| [gRPC с Node.js](https://github.com/decoyhq/decoy/tree/main/examples/grpc-node)                              | Как вернуть сообщение protobuf или ошибку со статусом gRPC.                   |
| [WebSocket с Node.js](https://github.com/decoyhq/decoy/tree/main/examples/ws-node)                           | Как ответить на сообщение или отправить его в открытый сокет.                 |
| [Transformers для HTTP и WebSocket](https://github.com/decoyhq/decoy/tree/main/examples/ws-transformer-node) | Как имитировать двоичные данные HTTP и WebSocket с помощью воркеров и команд. |
| [TLS с Node.js](https://github.com/decoyhq/decoy/tree/main/examples/tls-bff-node)                            | Как обращаться к HTTPS-, HTTP- и gRPC-сервисам из одного приложения.          |

Инструкции по настройке рабочей области и команду для запуска всех примеров см. в [руководстве для участников проекта](https://github.com/decoyhq/decoy/blob/main/CONTRIBUTING.md#commands).
