Сделайте так, чтобы `GET /users/123` возвращал данные Ады. Проверив ответ, добавьте второй вариант и переключитесь на него без остановки сервера.

## Установите CLI

Для установки в проект нужен Node.js 24 или новее. Выполняйте команду в каталоге с манифестом пакета. Если каталог пуст, сначала выполните `npm init -y`. Также понадобятся POSIX-совместимая оболочка и curl.

<PackageManagerTabs
  command={{
    npm: 'npm install -D @decoyhq/cli',
    pnpm: 'pnpm add -D @decoyhq/cli',
    bun: 'bun add -d @decoyhq/cli',
  }}
/>

[Установить отдельный бинарный файл](../install/index.mdx).

## Определите ответ с данными пользователя

Создайте каталог для файлов моков.

```sh title="Terminal: create the Route directory"
mkdir -p mocks/routes
```

Сохраните следующий [Route](../terms/index.md#route) в `mocks/routes/users.yaml`. Он обрабатывает `GET /users/{id}`. [Case](../terms/index.md#case) `user-123` выбирает запросы с ID `123`, а его [Behavior](../terms/index.md#behavior) `success` возвращает данные Ады.

```yaml title="mocks/routes/users.yaml"
id: users-by-id
transport: http
match: { method: GET, path: '/users/{id}' }

cases:
  user-123:
    match: { pathParams: { id: '123' } }

    behaviors:
      success:
        status: 200
        body: { id: '123', name: Ada }
```

Создайте [Collection](../terms/index.md#collection) `happy-path`, чтобы при запуске Decoy использовал ответ `success`.

```yaml title="mocks/collections.yaml"
- id: happy-path
  routes: [users-by-id:user-123:success]
```

## Запросите данные пользователя

Запустите сервер из каталога, содержащего `mocks/`. Оставьте этот терминал открытым. Флаг `--watch` позволит применить изменения файлов на следующем шаге.

<PackageManagerTabs
  command={{
    npm: 'npm exec --package=@decoyhq/cli -- decoy serve --routes mocks/routes --collections mocks/collections.yaml --port 8080 --watch',
    pnpm: 'pnpm exec decoy serve --routes mocks/routes --collections mocks/collections.yaml --port 8080 --watch',
    bun: 'bun run decoy serve --routes mocks/routes --collections mocks/collections.yaml --port 8080 --watch',
  }}
/>

Если вы установили отдельный бинарный файл, выполните ту же команду, начиная с `decoy serve`.

Во втором терминале запросите данные пользователя.

```sh title="Terminal 2: request the user"
curl -i http://localhost:8080/users/123
```

Убедитесь, что получили **200 OK** и такое тело ответа:

```json title="200 OK response body"
{ "id": "123", "name": "Ada" }
```

## Переключите ответ на 404

Замените файл Route этой версией. Она добавляет Behavior `missing` рядом с `success`.

```yaml title="mocks/routes/users.yaml"
id: users-by-id
transport: http
match: { method: GET, path: '/users/{id}' }

cases:
  user-123:
    match: { pathParams: { id: '123' } }

    behaviors:
      success:
        status: 200
        body: { id: '123', name: Ada }

      missing:
        status: 404
        body: not found
```

Добавьте вторую Collection в конец `mocks/collections.yaml`. Её [Behavior address](../terms/index.md#behavior-address) заканчивается на `missing`, поэтому для того же запроса теперь доступен другой ответ.

```yaml title="mocks/collections.yaml (append this entry)"
- id: user-missing
  routes: [users-by-id:user-123:missing]
```

Когда Decoy перечитает файлы, переключите Collection из второго терминала.

```sh title="Terminal 2: switch to user-missing"
curl -X POST http://localhost:8080/__decoy__/control/useCollection \
  -H 'content-type: application/json' \
  -d '{"collection":"user-missing"}'
```

Повторите исходный запрос. На этот раз вы получите **404 Not Found** с телом `not found`.

```sh title="Terminal 2: request the same user again"
curl -i http://localhost:8080/users/123
```

Попробуйте обратиться по пути, для которого мок не настроен:

```sh title="Terminal 2: request an unmocked path"
curl -i http://localhost:8080/orders
```

Убедитесь, что получили **501 Not Implemented** и `x-mock-miss: true`. Decoy сообщает, что не совпало, вместо того чтобы пересылать запрос реальному сервису. Подробнее — в разделе [Что происходит, если мок не найден](../routes/index.md#misses-are-fail-closed).

Остановите Decoy сочетанием Ctrl+C в терминале, где запущен сервер.

Чтобы сохранить настройки в проекте, [перенесите флаги в `decoy.yaml`](../config/index.md). Чтобы сопоставить запрос с другим пользователем, добавьте [Case](../routes/index.md#case-match). Для переключения ответа из браузерного теста настройте [Playwright](../playwright/index.mdx) или [Testplane](../testplane/index.mdx).
