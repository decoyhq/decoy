В [быстром старте](quick-start/index.mdx) вы настроите два ответа на один запрос: данные пользователя и ошибку 404. Там есть команды установки, примеры YAML и запросы для проверки. Если вам нужен только CLI, перейдите к [установке](install/index.mdx).

## Настройка моков

| Задача                                                          | Руководство                                                                         |
| --------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Сопоставить путь, проверить тело запроса или задержать ответ    | [HTTP Routes, Cases и Behaviors](routes/index.md)                                   |
| Переключить сразу несколько ответов                             | [Collection](collections/index.md)                                                  |
| Вернуть сообщение protobuf или поток ответов                    | [gRPC](grpc/index.md)                                                               |
| Ответить на сообщение WebSocket или закрыть соединение          | [WebSocket](websocket/index.md)                                                     |
| Декодировать данные перед сопоставлением или закодировать ответ | [Transformers](transformers/index.md) и [Pipelines](transformer-pipelines/index.md) |

## Управление Decoy из теста

Используйте [фикстуру Playwright](playwright/index.mdx) или [плагин Testplane](testplane/index.mdx), чтобы направлять запросы браузера в Decoy. У каждого теста своя сессия. Один тест может получить ошибку, пока другой проверяет успешный ответ.

Для curl и других HTTP-клиентов используйте [Control API](sessions-and-control/index.md). Готовые проекты с моками собраны в разделе [Готовые примеры](examples/index.md).
