Начните с [первого мока](quick-start/index.mdx). Вы настроите один запрос так, чтобы он сначала возвращал данные пользователя, а затем — ошибку 404. В руководстве есть инструкции по установке, оба YAML-файла и команды для проверки ответов. Если нужен только CLI, [выберите способ установки](install/index.mdx).

## Управление Decoy из теста

Используйте [фикстуру Playwright](playwright/index.mdx) или [плагин Testplane](testplane/index.mdx), чтобы направлять запросы браузера в Decoy. Каждый тест получает отдельную Session: один тест может выбрать ошибку, пока другой по-прежнему получает успешный ответ.

Для curl и других HTTP-клиентов используйте [Control API](sessions-and-control/index.md). Готовые проекты с моками собраны в разделе [Примеры для запуска](examples/index.md).
