# Устранение неполадок

Начните с того, что увидел клиент: соединение не установилось, мок не найден или пришёл корректный, но неожиданный ответ.

## Клиент не может подключиться

Убедитесь, что Decoy слушает на URL, который использует клиент. Для локального сервера с портом по умолчанию:

```sh title="Check whether Decoy is listening"
curl -i http://localhost:8080/__decoy__/health
```

Ожидайте `200 OK` и `{"status":"ok"}`. Если подключение не удалось, проверьте адрес и порт в журнале запуска Decoy. Если включён [TLS](../tls/index.md), используйте `https://` и добавьте в доверенные настроенный сертификат или локальный CA. Исправный сервер всё равно может не найти мок: проверка работоспособности не сопоставляет Route и не читает Session.

## Decoy не нашёл мок

В HTTP ответ `501` с `x-mock-miss: true` означает, что ни одно активное Case не совпало. Проверьте `candidates` в ответе: там перечислены проверенные Behavior address и причины несовпадения. Например, `field: pathParams.id` указывает на проверку параметра URL. Убедитесь, что нужное Behavior включено в активную [Collection](../collections/index.md), затем сравните фактический запрос с [Route и Case](../routes/index.md#case-match).

Запустите Decoy в [терминальном интерфейсе](../tui/index.md), чтобы смотреть недавние запросы через `Ctrl+O`. Для gRPC см. [Несовпадения и ошибки](../grpc/index.md#misses-and-errors).

## Переключение Collection не изменило ответ

Проверьте, что переключение и запрос относятся к одной [Session](../sessions-and-control/index.md#sessions). Запрос curl без `x-mock-session` использует Session по умолчанию. Playwright и Testplane создают отдельную Session для каждого теста. Переключите её через адаптер до того, как страница отправит запрос.

Если Session верная, проверьте, не совпадает ли более позднее Case той же Collection и нет ли активного переопределения Behavior. В терминальном интерфейсе `/status` показывает выбранную Collection и переопределения активной Session. Если вы только что изменили файл, убедитесь, что [перечитывание](../config/index.md#reloading) прошло успешно: при ошибке проверки Decoy продолжает использовать предыдущую конфигурацию.
