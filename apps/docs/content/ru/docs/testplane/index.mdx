# Testplane

`@decoyhq/testplane` — плагин для [Testplane](https://testplane.io). Он запускает `decoy` на время прогона, выделяет каждому тесту свою Session, направляет вызовы API из браузера в Decoy и предоставляет Control API через `decoy(browser)`. Нужны Node.js 24 или новее и Testplane 8 или новее.

Для настройки нужна одна запись в `plugins`:

```ts title=".testplane.conf.ts"
import type { DecoyOptions } from '@decoyhq/testplane'
import type { ConfigInput } from 'testplane'

export default {
  gridUrl: 'local',
  baseUrl: 'http://127.0.0.1:4173',
  browsers: { chrome: { desiredCapabilities: { browserName: 'chrome' } } },

  plugins: {
    '@decoyhq/testplane': {
      command: 'decoy serve --config mocks/decoy.yaml',
      urls: '**/api/**', // browser requests sent to Decoy
      collection: 'happy-path', // each test's Session starts here
    } satisfies DecoyOptions,
  },
} satisfies ConfigInput
```

Теперь [переключите ответы в тесте](responses/index.md).

## Параметры

| Параметр              | По умолчанию                  | Назначение                                                                         |
| --------------------- | ----------------------------- | ---------------------------------------------------------------------------------- |
| `enabled`             | `true`                        | `false` отключает плагин, не удаляя его.                                           |
| `url`                 | `http://127.0.0.1:8080`       | Адрес Decoy.                                                                       |
| `command`             | `decoy serve`                 | Команда оболочки, которую плагин запускает, если Decoy не работает.                |
| `cwd`                 | Каталог файла конфигурации    | Рабочий каталог для `command`.                                                     |
| `reuseExistingServer` | `true` локально, `false` в CI | Использовать уже работающий Decoy, если он отвечает на проверку работоспособности. |
| `timeout`             | `60000`                       | Сколько миллисекунд плагин ждёт успешной проверки.                                 |
| `urls`                | Нет                           | Шаблон glob (`*` внутри сегмента, `**` через сегменты), RegExp или список.         |
| `collection`          | Collection Decoy по умолчанию | Начальная Collection Session каждого теста.                                        |

Как и в Playwright, шаблон glob в `urls` проверяет полный URL запроса: `*` действует в пределах одного сегмента пути, `**` может захватывать несколько, а `{api,graphql}` подходит для любого из двух вариантов. Шаблон должен начинаться с `*` или схемы (`'**/api/**'`, `'http://localhost:3000/api/**'`). При загрузке плагин отклоняет шаблоны вроде `'/api/**'`, которые не могут совпасть с полным URL. Запросы, не совпавшие ни с одним шаблоном, идут в реальную сеть.

При запуске `command` в `PATH` добавляется `node_modules/.bin` (поиск от `cwd` вверх). В конце прогона плагин отправляет SIGTERM, а если Decoy не вышел через 8 секунд — SIGKILL (в Windows — `taskkill /T /F`).

## Ограничения

- Для перенаправления запросов (`urls`) нужен Chrome или Chromium: плагин использует CDP через `browser.getPuppeteer()` и в Sessions WebDriver Classic, и в BiDi (`webSocketUrl: true`). В других браузерах каждый тест завершится с сообщением об ошибке.
- Testplane повторно использует браузер в нескольких тестах, поэтому запрос, который ещё выполняется в конце теста, может попасть в Session следующего. Перед завершением теста дождитесь, пока страница закончит работу.

Рабочая версия есть в [`examples/testplane-ts-e2e`](https://github.com/decoyhq/decoy/tree/main/examples/testplane-ts-e2e).
