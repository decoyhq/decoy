# Установка

Decoy — один нативный исполняемый файл `decoy`. Выберите способ установки, подходящий для вашего проекта.

## Скрипт установки (отдельный бинарный файл)

```sh title="macOS / Linux"
curl -fsSL https://github.com/decoyhq/decoy/releases/latest/download/install.sh | sh
```

```powershell title="Windows PowerShell"
irm 'https://github.com/decoyhq/decoy/releases/latest/download/install.ps1' | iex
```

Скрипт устанавливает релиз с пометкой Latest в `~/.decoy/bin`, предварительно проверив контрольную сумму по файлу `SHA256SUMS` из релиза. Предварительные релизы не считаются Latest, пока им не присвоят эту пометку. Переменная `DECOY_INSTALL_DIR` задаёт другой каталог установки. В Windows скрипт добавляет каталог в пользовательский `PATH`; в macOS и Linux это нужно сделать вручную.

Чтобы зафиксировать версию, например в CI, замените `latest/download` в URL установщика на `download/<tag>`, подставив точный тег из [GitHub Releases](https://github.com/decoyhq/decoy/releases). По умолчанию установщик из релиза устанавливает именно этот релиз. Чтобы выбрать другую версию, задайте `DECOY_VERSION` перед запуском или передайте версию shell-скрипту через `sh -s -- <version>`.

Для обновления на месте выполните `decoy upgrade`. Команда повторно запускает установщик Latest в каталоге текущего бинарного файла, кроме случаев, когда установлен уже Latest или более новый предварительный релиз. Чтобы перейти на другую версию, запустите её установщик, задав `DECOY_INSTALL_DIR`. Если Decoy установлен как зависимость проекта, обновляйте его через менеджер пакетов.

## Установка в проект JavaScript или TypeScript

Для npm-пакета нужен Node.js 24 или новее. Добавьте `@decoyhq/cli` в зависимости для разработки из каталога проекта. Отдельному бинарному файлу Node.js не нужен.

<PackageManagerTabs
  command={{
    npm: 'npm install -D @decoyhq/cli',
    pnpm: 'pnpm add -D @decoyhq/cli',
    bun: 'bun add -d @decoyhq/cli',
  }}
/>

`@decoyhq/cli` устанавливает через необязательную зависимость только бинарный файл для вашей платформы: Linux x64/arm64, macOS x64/arm64 или Windows x64. Скрипты установки пакетов при этом не запускаются.

Проверьте установку из каталога проекта: `npm exec -- decoy --version`, `pnpm exec decoy --version` или `bun run decoy --version`.

## Релизы на GitHub

Для каждого релиза опубликованы архивы для тех же платформ и файл `SHA256SUMS`: `decoy-<version>-<target>.tar.gz` (`.zip` в Windows). Распакуйте архив и поместите `decoy` в каталог из `PATH`. Бинарные файлы для Linux собраны с musl и используют mimalloc. При параллельной нагрузке он намного быстрее аллокатора musl, но удерживает больше памяти (около 30 МБ в простое).

## Сборка из исходников

```sh title="Build the Decoy binary"
cargo build --release -p decoy
```

Проверьте сборку командой `./target/release/decoy --version` (в Windows — с расширением `.exe`). Чтобы `@decoyhq/cli` запускал этот файл, укажите его полный путь в `DECOY_BINARY_PATH`.
