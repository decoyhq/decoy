# Transformers

Transformer принимает одно значение и возвращает другое. Например, он может извлечь ID из объекта, распаковать байты или превратить отметку времени в строку с датой.

Transformers работают в Routes HTTP, gRPC и WebSocket. [Pipeline](../transformer-pipelines/index.md) связывает их: каждый шаг получает результат предыдущего. Для входа и выхода предусмотрены отдельные списки, поэтому в каждом направлении можно использовать своё преобразование.

## Выберите команду или воркер

Команда запускается заново при каждом вызове. Она читает из `stdin` и записывает результат в `stdout`. Выбирайте команду, если подходящая программа, например `gzip`, уже существует.

Воркер остаётся запущенным между вызовами. Он может хранить состояние отдельно для каждого соединения или использовать protobuf-дескрипторы, загруженные Decoy. Напишите воркер с помощью [TypeScript SDK](../transformer-sdk/index.mdx) или реализуйте [протокол воркера](../transformer-worker-protocol/index.md) на другом языке.

[Настройте Pipeline](../transformer-pipelines/index.md), чтобы связать шаги и узнать, какие транспорты их поддерживают.
