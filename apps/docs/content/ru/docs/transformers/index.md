# Transformers

Преобразование (Transformer) принимает одно значение и возвращает другое. Например, можно извлечь ID из объекта, распаковать сжатые данные или отформатировать дату.

Преобразования работают в маршрутах HTTP, gRPC и WebSocket. В [цепочке (Pipeline)](../transformer-pipelines/index.md) каждый шаг получает результат предыдущего. Для входа и выхода можно задать разные шаги.

## Выберите команду или воркер

Decoy запускает команду заново при каждом вызове. Команда читает данные из `stdin` и пишет результат в `stdout`. Этот способ удобен, когда уже есть готовая утилита, например `gzip`.

Воркер остаётся запущенным между вызовами. Он может хранить состояние отдельно для каждого соединения или использовать protobuf-дескрипторы, загруженные Decoy. Напишите воркер с помощью [TypeScript SDK](../transformer-sdk/index.mdx) или реализуйте [протокол воркера](../transformer-worker-protocol/index.md) на другом языке.

В разделе [Настройка цепочки преобразований](../transformer-pipelines/index.md) показано, как объединить шаги и подключить их к маршруту.
