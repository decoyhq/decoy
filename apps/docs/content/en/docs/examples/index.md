# Runnable examples

Each example includes mock files and a client or test suite you can run from the Decoy repository.

| Example                                                                                                    | What it shows                                                        |
| ---------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| [Playwright](https://github.com/decoyhq/decoy/tree/main/examples/playwright-ts-e2e)                        | Switch the response a page sees in a browser test.                   |
| [Testplane](https://github.com/decoyhq/decoy/tree/main/examples/testplane-ts-e2e)                          | Route browser requests to a per-test Session.                        |
| [gRPC with Node](https://github.com/decoyhq/decoy/tree/main/examples/grpc-node)                            | Return a protobuf message or a gRPC status error.                    |
| [WebSocket with Node](https://github.com/decoyhq/decoy/tree/main/examples/ws-node)                         | Reply to a message or push one to an open socket.                    |
| [HTTP and WebSocket Transformers](https://github.com/decoyhq/decoy/tree/main/examples/ws-transformer-node) | Use workers and commands to mock binary HTTP and WebSocket payloads. |
| [TLS with Node](https://github.com/decoyhq/decoy/tree/main/examples/tls-bff-node)                          | Call HTTPS, HTTP, and gRPC backends from one app.                    |

For workspace setup and the command to run every example, see [Contributing](https://github.com/decoyhq/decoy/blob/main/CONTRIBUTING.md#commands).
